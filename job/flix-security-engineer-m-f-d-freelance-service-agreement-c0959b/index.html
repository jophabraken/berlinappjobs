We are looking for an experienced Security Engineer (m/f/d) to support Flix on a project basis through a service agreement collaboration. The consultant will provide expertise in client-side security, incident response automation, and security tooling across Flix's technology environment. The collaboration will involve working with security engineers, infrastructure and software engineers, and business stakeholders to improve Flix's overall security posture and reduce manual security operations.

Scope of Services

  • Set up and configure client security tools related to email security, access management, and asset protection in collaboration with the internal security team
  • Automate incident response processes and repetitive security workflows using Python — including phishing triage, secret rotation, and M365/Graph automation — to reduce manual effort and increase team capacity
  • Support incident response activities related to client-side security events such as account compromise and phishing incidents, collaborating with stakeholders across the organisation
  • Review and assess existing security measures and contribute concrete recommendations for improving detections, response runbooks, and overall security services at Flix

About You

  • Proven experience with client security applications, including email security, phishing mitigation, and endpoint protection
  • Hands-on experience with incident response and service desk ticket handling
  • Solid programming skills in Python with a focus on clean, maintainable automation code
  • Experience with monitoring or SIEM tools such as Splunk, ElasticSearch, or Datadog
  • Strong collaboration and communication skills when working with both technical and business stakeholders
  • Professional proficiency in English (written and spoken)

Collaboration Model

  • Cooperation based on a service agreement with independent delivery of agreed services and invoicing
