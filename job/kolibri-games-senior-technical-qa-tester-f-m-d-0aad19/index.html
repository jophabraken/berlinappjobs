Senior Technical QA Tester (f/m/d) 


We’re looking for a Senior Technical QA Tester to join the Idle Bank Tycoon team in Berlin. You’ll own the quality of the game end-to-end: from feature testing and test automation to performance profiling and process improvement; embedded in a cross-functional team alongside Product, Game Design, and Engineering.

If you enjoy both the technical depth of engineering and the craft of making sure things actually work for real players, this might be the right fit.

Responsibilities

    • Own features and test coverage end-to-end, from identifying QA flows and edge cases based on product requirements to release sign-off and post-release monitoring of the game.
    • Design, write, and review test plans and test maps; review submissions from other QA team members and define the QA strategy for complex features.
    • Perform technical QA analysis, when needed, including runtime profiling, memory analysis, CPU/GPU usage, and build size validation on iOS and Android.
    • Monitor and investigate regressions: frame rate drops, load time increases, APK/IPA size changes across builds.
    • Proactively coordinate team playtests and continuously monitor release performance, raising red flags early.
    • Drive continuous improvements to QA process and tooling, partnering with the QA manager on workload and priorities across internal & external testers.
    • Run and maintain automated test suites on our in-house Test Automation Platform, and convert manual test cases into automated tests using the platform.

Required Skills

  • Strong hands-on manual QA/testing expertise across the full test lifecycle, ideally in mobile or gaming.
  • Solid understanding of mobile game performance metrics: profiling, memory, build sizes, and frame pacing on iOS and Android.
  • Experience with test management tools (Xray, TestRail, Zephyr or similar) and Agile/Scrum workflows in Jira.
  • Experience coordinating QA workload across internal and external testers.
  • Familiarity with AI-assisted tooling for testing, triage, or workflow automation.
  • Basic Python knowledge, enough to run automated test suites and convert manual tests to automation using our in-house Test Automation Platform.
  • Strong communicator in English (written and verbal) across cross-functional teams.
  • Proactive, ownership-driven, and comfortable making calls in ambiguous situations.

Desirable Skills

  • Extensive QA experience in mobile gaming, particularly F2P/LiveOps.
  • Experience with CI/CD tools such as Jenkins or GitLab.
  • Familiarity with Unity.
  • Hands-on experience with mobile profiling tools (Xcode Instruments, Android Profiler, or equivalent).
  • Familiarity with Firebase, SDKs, and third-party plugins.
  • Basic SQL and familiarity with data pipelines.
